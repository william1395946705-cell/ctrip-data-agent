携程自动采集测试版 0.3.2（安装与表格导出说明）

Windows / macOS：首批使用桌面 Chrome，Edge 可参与兼容性测试。
本包不适用于直接安装到 Safari 或 Firefox。

安装：
1. 将 ZIP 完整解压到固定文件夹，不要在压缩包里直接运行，不要安装后删除目录。
2. Chrome 地址栏输入 chrome://extensions（Edge 使用 edge://extensions）。
3. 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 在同一浏览器正常登录本人或授权酒店的携程 eBooking。
5. 打开或刷新普通携程页面，加载稳定后自动采集，不需要进入报表页。
6. 点击扩展图标，确认版本0.3.2。自动采集可以暂停，也可以手动采集。

查看和导出表格：
点击扩展里的“查看本地数据表 / 导出表格”。表格自动读取本浏览器已有采集记录。
点击“导出表格（CSV）”，用 Excel 或 WPS 打开。CSV 有中文列名、北京时间、UTC时间、统计日期、全部核心指标、失败模块和复核提示。
百分比按百分数显示，空白不是零。酒店ID及排名使用文本前缀保护，部分表格软件可能显示前置单引号。
下载由浏览器处理，一般放入“下载”目录。如希望放入扩展文件夹，可在浏览器设置中开启“下载前询问保存位置”后手动选择。
扩展不会自动向安装目录写文件；数据实际保存在本浏览器扩展存储中。
本版本沿用最近记录缓存，默认20次、配置上限100次（所有门店合计），表格页会显示当前上限。请定期导出备份。
数据不会发送给开发者或其他电脑。卸载扩展、清除扩展数据会删除记录；更换浏览器也不会自动迁移。

测试：
不点立即采集，刷新普通页，确认结果trigger为automatic。当天采到完整结果后再刷新，时间应不变。
本次完整快照有身份待复核提示时，也停止当天重复自动请求，不代表已完成酒店身份自动验证。
首次使用请核对门店及指标。“需人工复核”不是网络失败；采集异常不能视为零或无违约。
30天ROAS、有违约样本仍未完成验证。Windows与Edge需要实际试用反馈。
电脑关机、浏览器关闭或携程未登录时无法采集。跨天后下一次正常打开、刷新或切页再触发。

更新：替换程序文件后在扩展管理页点“重新加载”，确认版本，再手动刷新一次携程页面。
分享时仅发送原始测试ZIP，勿把导出的酒店表格混入程序包。
